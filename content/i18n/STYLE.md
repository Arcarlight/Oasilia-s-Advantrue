# 《Oasis》本地化规范（翻译时必须遵守）

游戏：沙漠蜻蜓（Flygon）女主人公**欧亚西莉亚**的卡牌 roguelike。整体语气**轻松、有画面感、偶尔俏皮** ——
不必太过严肃，可以好玩些。带「」的是角色在说话（主角自称「わたし」，台词里可以口语化）。

## 二、排版习惯（照抄，别创新）

- 日文：**数字两侧留半角空格**（`最大HPの 20%`、`どく 1 層`、`攻撃 +2`）；引号用「」；叙述用常体（だ／である）。
- 英文：`Deal 13 damage.` 这种紧凑写法；句首大写、句末句号；缩写可用。
- 数字一律半角；`**加粗**`、`\n`、`<b>`/`<code>` 标记原样保留。

## 三、专有名词（宝可梦原版风格）

- **招式名 / 道具名 / 属性名 / 物种名一律不写汉字**：たいあたり / キズぐすり / じめん / フライゴン。
- **状态名全平假名**：どく / もうどく / やけど / じゃくたい / しゅっけつ；档位「野生」写 `やせい`。
- 物种名用**官方译名**（サンド / フライゴン / ポッポ / ヤヤコマ / テッポウオ / ヨワシ / キングラー / キモリ / バルジーナ / マンタイン）。
- 汉字只出现在**说明文**里。

## 四、⚠️ 这个世界里**没有现实动物**

只能出现宝可梦。不要写「鸟 / 鱼 / 螃蟹 / 蜥蜴 / 秃鹫 / 蜂 / 老鼠」这类现实动物，
按语境换成宝可梦（例：一只鸟 → ポッポ / A Pidgey；一条鱼 → テッポウオ / A Remoraid）。
例外：**贝壳**（景物）、已经点名的物种（秃鹫娜 / 巨翅飞鱼…）。

## 五、人称（写错一眼就是翻译腔）

- **日文旁白不用「お前」**（那是很粗的男性口吻），叙述优先**省略主语**，非写不可时用「あなた」。
- 「奴（やつ）」这类粗话在旁白里也收掉。
- 「」里是角色在说话，那里可以口语化。
- 英文旁白用 you；台词按角色性格来。

## 六、硬性规则

1. 键 = 中文原文，**一个字都不能改**（含标点、空格、换行）。
2. 占位符 `{name}` `{n}` `{heal}` `{hp}` `{gold}` `{item}` `{card}` 一个都不能少、不能多。
3. `\n` 必须保留（JSON 里写 `\n`）。
4. 不要留中文；不要加括号注音、不要加解释。
