敌人图鉴详情页改版：跟着鼠标转的行走图 + 击败奖牌 + 书本图标

用户要求（三批）：
1. 「敌人图鉴里的图会有缩放有问题。能否直接把框移除，变成行走图、立绘、小图标都放在左上，
   右边放名称、编号、称号、属性等，下面再列出其拥有的卡牌和挑战次数、失败次数，
   以及模仿它可能的口吻说一句话？（这个只有见过并打败的宝可梦才能看到。）」
2. 「敌人的行走图都是朝左的，可以让行走图的方向指向鼠标的方向」——八向；缩放到同一行。
3. 「削弱用蓝色下箭头 / 加 buff 用红色上箭头」「敌人图鉴图标换成书」。

详情页（src/ui/codex.js）：
- 排版改成 .dex-detail-top 两列：左上三张图（行走图 / 回合立绘 / 小图标，**不再一张图一个框**），
  右边名称 / 编号 / 档位 / 地图 / 属性 / 称号 + 战绩。
- 行走图跟着鼠标转：sprites.js 新增 canvas.setDir(row)（换朝向行、动画接着播）与
  canvas.contentDirs()（这个物种支持哪些朝向 —— 素材里 208/214 只画满 8 向，6 只没画满，
  空行会退回第一行有内容的）。dirFromPoint(cx,cy,px,py) 把鼠标方向映到 DIR 的 8 个行。
- 战绩：挑战 / 击败 / 失败 / 胜率 / 招式数。记录侧新增 meta.facedCount（开打 +1）与
  meta.slainCount（打赢 +1），老存档没有计数时退回「打赢过 = 1 次」。
- 口吻台词：只有击败过（.slain）才显示，按击败次数轮换它的出场台词（第 N 次打赢听第 N 句）。
  用的是既有的 lines，不再新写 193 句 —— 也就永远和战斗里听到的那句对得上。
- 击败奖牌：5 铜 / 15 银 / 25 金 / 50 紫金，挂在行走图右上角，外加一条四段进度条。
- 修掉一个自己踩的坑：画布是异步建好的，原先 clear(walkBox) 会把已经挂上去的奖牌一起清掉
  （15 次银牌死活不出现）—— 改成只清 .dex-walk-stage。

图标：

- 新增 ico-arrow_up_red / ico-arrow_down_blue，卡面角标的「增益 / 削弱」换掉温度计
