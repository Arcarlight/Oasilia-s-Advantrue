敌人招式按属性重排：每只宝可梦都有本系招式了

用户报的：「现在很多宝可梦没有本系招式的卡牌，你可以加入一些，并且改掉他们技能池内
莫名其妙的技能。」并要求「现在的平衡就是标准」。

问题：招式池是手挑的混合池（kit_ground 这种），里面掺着异系牌 —— 幽灵系的怨影娃娃
在扔「流沙地狱」、冰宝（冰）在扔「岩崩」、天蝎（地面/飞行）在用恶系池。没有任何环节
会把「池子的属性」和「这只怪的属性」放在一起看，因为**卡牌当时根本不知道自己是什么属性**。

做法（四步，每步都有门禁）：
- 卡牌登记属性：content/cards.json 的每张卡都有 types（273 张全登记），
  build-content 硬性要求「没有 types 直接报错」。
- 按属性组池：tools/build-enemy-kits.mjs 生成 kit_t_<属性> / kit_t_<属性>_hi
  （18 种属性 × 2 = 36 个池），池子 = 该属性攻击牌 + 两张通用小工具
  （抓挠/撞击/扬沙/缩壳/瞪眼/守住 —— 不带伤害、谁的池子都能放）。
- 按属性指派：tools/apply-enemy-kits.mjs 按物种真实属性挑池子，双属性选**出场更少**的那个
  （天蝎走飞行、耿鬼走幽灵）；精英/首领拿 _hi；准神与传说在 enemy-kit-plan.mjs 里点名。
  193 只全部改完，0 只还在用老池子。
- 门禁钉住：每只敌人的池子里至少一张本系攻击牌；kit_t_* 池子里的攻击牌必须都是该属性；
  ?dgkit=1 会真的开 60 场战斗读敌方牌堆（本系 447 张 / 越系 0 张，专属招式按设计豁免）。

新卡 74 张（火花/十万伏特/冰冻牙/月亮之力/铁尾/近身战/暴风雪/断崖之剑/影子偷袭/潜灵奇袭/
幻象光线/妖精之风/金属爪/加农光炮/高速星星…），冰/超能/妖精/电从前几乎一张本系都没有。

平衡（用户把改动前的数值定成标准，所以新池子逐项对齐现有池子的同档中位数）：
  基线 低档 8 张 / 攻击 6~7 / 平均费 1.00 / 平均威力 105 / 每AP ≈93
  现在 低档 7.6 张 / 攻击 5.4 / 平均费 1.40 / 平均威力 118 / 每AP 82
「每 AP 威力」才是难度口径（敌人每回合 AP 固定），故意压到比基线低一档，
把「牌更贵」那点劣势换成余量；tools/rescale-kit-cards.mjs 负责这条口径。
实测 measure-balance 300 场/档：杂兵 100% 不变、精英/首领在大样本下无系统性偏移；
全流程 simulate-run 400 局：通关率 11.3% → 13.5%，平均到第 4.15 → 4.04 章。

顺带：修掉 5 只把属性写成「超能力」的物种（会让它们挑不到任何池子）；
night_slash 从恶系改回幽灵系（它是「暗影爪」）；删掉重复的 wild_charge。
